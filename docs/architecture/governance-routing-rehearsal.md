# Governance Routing Rehearsal

This document exists to support synthetic governance PRs that exercise:

- CODEOWNER review routing
- replay validation
- frontend contract validation
- protected branch enforcement

The content below is intentionally narrow:

- routing should be observable on a live PR
- workflow execution should remain deterministic
- validation artifacts should be uploaded for inspection
- merge blocking should remain active until human approval

This rehearsal does not change runtime behavior.
